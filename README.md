# Credit Card Fraud Detection

## Overview

This project uses Machine Learning to identify fraudulent credit card transactions. The dataset contains anonymized transaction features along with transaction amount, time, and a target class indicating whether the transaction is fraudulent.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Models Used

1. Logistic Regression
2. Random Forest Classifier

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1 Score
* Confusion Matrix

## Dataset

Credit Card Fraud Detection Dataset

Target Variable:

* 0 = Legitimate Transaction
* 1 = Fraudulent Transaction

## How to Run

```bash
pip install -r requirements.txt
python fraud_detection.py
```
